# Vision_mate_AI
VisionMate AI – Real-time edge AI camera assistant. Count objects, detect hazards, generate scene descriptions, recognize gestures. Offline, privacy-first, >91% accuracy at 25-30 FPS. Built with YOLOv8, MobileVLM, MediaPipe, Streamlit.

**VisionMate AI** transforms a standard webcam into a powerful, real‑time visual intelligence assistant. All processing happens **on‑device (edge computing)** – no cloud, no internet dependency, full privacy.

## 🚀 Key Features

- ✅ **Object Counting** – Real‑time bounding boxes with dynamic class selector (25–30 FPS, >91% accuracy).
- ✅ **Scene Description** – Natural language scene summaries generated by a quantised Vision‑Language Model (MobileVLM‑1B, INT4) in under 3 seconds.
- ✅ **Safety Alerts** – Detects missing PPE, fire, spills, and obstructions (false positive rate <6%).
- ✅ **Gesture Recognition** – Hands‑free control via MediaPipe: thumbs up, peace sign, open palm (>30 FPS on CPU).
- ✅ **Distance Estimation** – Coarse monocular depth heuristics for spatial awareness.
- ✅ **Attendance Counting** – Compare detected head count against registered class strength for instant roll‑call.
- ✅ **Actionable Insights** – Scene‑aware suggestions to guide operators.
- ✅ **Retail Analytics** – Simulates footfall heatmaps and detects shelf gaps.
